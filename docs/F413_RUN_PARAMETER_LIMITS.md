# F413 走行パラメータと固定上書きの撤去（2026-09-21）

対象は共通F413ファームのmini_r2・mini_r3。
識別版は `f413pre-run-params-t0.2` / `mini-r3-run-params-t0.17`。
最新mode6ログで判明した速度推定1200 mm/sクリップを撤去し、
有効な走行パラメータより優先されていた立上げ・調整用の値を監査した。

| 箇所 | 修正後 |
| --- | --- |
| IMU併用速度推定の±1200 mm/s制限 | 撤去。実測は目標速度超過・逆転もそのままfeedbackとログへ渡す |
| 直進1500・斜め1000・ターン500 mm/s、および吸引mode4/6の1200/1500例外 | 撤去。モードのターン速度とケースの直進/斜め速度を直接採用 |
| 発進速度の1500 mm/s制限 | 選択ケースのvmaxと加速度領域に従う。最終45 mm停止の入口速度も同じ条件で計算 |
| ターン共通2200 deg/s制限 | 撤去。最短は新設 `ShortestRunModeParams_t.turn_omega_max`（deg/s、0=制限なし）、探索は上限なし |
| 不正な最短ターン角/alphaの90 deg / 10000 deg/s²への置換 | 撤去。非有限・無効値は駆動前のprofile準備で拒否 |
| case0終端の加速度を最低3000 mm/s²へ引上げ | 撤去。ケースの加速度を守れる停止距離を事前計算・実行 |
| mode2 case6の固定テスト経路・壁補正OFF差替え | 撤去。保存迷路の経路生成とケース定義の壁制御/補正へ復帰 |
| 並進PID調整時の角度ゲインP=4/I=0/D=0差替え | 撤去。実fan状態で選んだFAN_ON/OFFの角度ゲインを使用 |
| 経路事前計算・ホスト時間計画の同じ速度/角速度制限 | 撤去。実行側と同じパラメータを使用、生成テーブルを更新 |

mini_r3 mode4/6の `turn_omega_max = 2200.0f` は、PR21シミュレータで
作成した既存ターン形状の入力値を明示的にパラメータへ移したもの。
角加速度・オフセットを変更せず、これまでの角速度波形を維持する。
mini_r2の全モードとmini_r3のその他モードは省略初期値0。
シミュレータ `tools/tuning/turn_tune.py` も選択モードのこの値を読み、
`--omega-max` で試算時に変更できる。上限だけ変更するとターン形状も変わるため、
同じ設定でalpha・オフセットを試算する。

case0の停止尾部は従来の最低45 mmから、必要なら長くなる。
例えば500 mm/s・1000 mm/s²なら125 mmを確保する。開始ログの `stop_mm`
に距離を表示し、駆動中は事前計算値を使用する。
斜め終端のテストは斜め用加速度を採用する。
mode6の1500 mm/s・25000 mm/s²では45 mmのまま。
通常の迷路走行は停止位置を伸ばさず、加減速不能な経路を従来どおり駆動前に拒否する。

F405のmini_r1/classic_r1制御・最短実行も監査したが、今回の1200推定上限や
F413立上げ用速度制限は適用されていない。実行コードの変更なし。
共通パラメータ構造体末尾にF413用の任意項目を追加したが、F405は参照せず、
NVMの保存形式にも含まれない。

PWM 100%の出力限界、角度補正の4000 deg/s制限、並進PID試験だけの姿勢補正60 deg/s制限、
停止・センサ異常・時間・バッファ容量のguardは動作保護であり、今回の走行速度上書きではない。
明示的に選ぶcase0試験経路・PID試験波形、角度累積モードの正確な45/90/135/180度、
既存UI仕様のmode2 case3→parameter case4対応も保持する。
経路探索用の格子形状seedは走行指令値ではなく、時間算出用の実パラメータと区別して維持した。

検証はホストのみ。実制御tickの±0.3/1.5/2.4/4.5 m/s、目標超過、fan ON/OFF、
ターン中/直進の速度feedback、異なるON/OFFゲイン、吸引立上げ/中止をASan/UBSanで検証。
両機体の6モード×9ケース、5 m/s直進・4.5 m/s斜め・4.3 m/sターンのパラメータ反映、
case0停止距離、mode4/6全10試験経路・mode6最短接続2736経路を検証。
既存path219、route preview33464、事前計算14210、slalom837、機体選択、
シミュレータ32テストおよびF413/F405ビルドがPASS。
実機書込・駆動・NVM操作は未実施で、固定上限を超える設定の床上走行は未検証。
調整中のローカルゲイン、fan duty、mode2加速度は保持し、この修正コミットには混在させない。
