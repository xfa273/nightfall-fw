t0.19の90°/180°ログで旋回追従は改善したが、待機中の低周波な方位変動と
発進後の約0.6°の追加ずれが再現した。t0.20では角度Iを外し、吸引停止保持から
発進するときの角速度Iと微分履歴をクリアする。測定角度と目標角度は保持する。
実機書込・駆動は行っておらず、改善確認は次回走行待ち。

## 発進ずれの原因と変更

発進前のエンコーダ左右差による角度もgyroと同方向へ変わるため、表示だけのずれではない。
タイヤ0.01413 m、200 CPR、トレッド0.0345 mでの発進時encoder角度は+0.737°/+0.369°。
量子化とタイヤ挙動の影響はあるが、gyroだけをゼロに戻す対策は適切でない。

静止保持中に、角度Iと角速度Iが蓄積していた。発進直前の角度I寄与は約+14/+13 deg/s。
90°ログでは角度+0.699°で既に負方向へ戻すべきなのに、角速度指令は+3.5 deg/sとなっていた。
角速度PI・FF・先行補償をログから分離すると、内側Iの旋回出力寄与も約+2.8/+1.8%残る。
発進時に外側Iだけリセットされ、内側Iは持ち越されるため、最初のFF過渡の後に
左旋回側の出力が残り、走りながら積分が戻るまで約0.6°余分に曲がっていた。
符号は `(右PWM−左PWM)/2` を正の左旋回とした。

- `KI_ANGLE_FAN_ON`: **0.1→0**。角度P=15、内側角速度P=0.8/I=0.006は維持。
  定常トルクの補償は内側PIへ任せ、静止摩擦下で外側Iも蓄積する状態を解消する。
- `f413_ctrl_set_velocity_profile()` の停止保持→非ゼロ速度プロファイル開始時に、
  fan稼働中・距離保持中・旧速度指令0・旧目標速度0・開始速度0・旋回プロファイルなし・
  旋回プロファイル指令0という条件で、角速度IとD履歴、FF微分履歴を原子的にリセット。
  初回の角加速度FFは0となり、保持解除による目標角速度の段差を慣性補償へ入力しない。
  角度/位置の測定値、目標角度、並進Iはクリアしない。前進/後退の両方を対象とする。
  動いている区間接続・旋回中・FAN_OFFでは従来どおり積分を保持する。
- fan 50%まで600 ms・100%まで1200 ms、到達後300 msと先行保持20 msは維持。
  発進前の新たな姿勢判定ゲートや追加の待機時間は設けない。

静止摩擦やファン反力自体を測定したモデルではないので、発進角度ゼロを保証するものではない。
次回は発進直前の角度、発進後70 msの追加ずれ、左右出力の符号を比較する。

## その他の調整・停止待ちの修正

180°では速度低下が残り、出力飽和はなかった。
`KP_VELOCITY_FAN_ON` を **0.35→0.45**へ増やし、短時間の負荷増加への応答を強める。
並進FF65/0.110/0.0100、速度I=0.001、角速度FF0.040/0.0008と各Dは維持。
直進速度が既に到達しているため、並進FF全体を増やす変更はしない。
180°のencoder積算角度とgyroには約6.5°の差があり、横滑り・有効トレッド等は未分離。
今回の速度P変更で実際の軌跡や速度不足がすべて解決するとは判定しない。

90°ログは走行開始後約0.48 sで停止し、目標522.379 mm・ログ実測522 mm、
速度指令は量子化表示で0となったまま1.4 s以降まで位置到達待ちが続いた。
実測距離列は1 mm刻みで、端数は絶対測定精度を意味しない。
seq4091→4092間に0.657 sの記録欠落があり、正確な終了過程はこのログだけでは断定できない。

production runnerでは、case0の停止尾部でも「実距離が目標を横切る」まで待った後で
初めて既存の整定チェック（位置0.00075 m、速度0.020 m/s、最大0.250 s）へ進んでいた。
そのため許容内で目標手前に静止しても、このチェックへ到達できなかった。
test modeでは減速プロファイル完了後に整定チェックへ進むよう変更。
位置/速度許容値は緩和せず、許容外の停止は既存0.250 sで中止する。
通常の迷路走行や非ゼロ速度区間の到達条件は変更しない。

## 対象と検証

- mini_r3のFAN_ONゲインのみ更新、識別版 `mini-r3-suction-start-t0.20`。
  起動時の積分処理はF413共通コードだがfan稼働中だけ対象。
  case0停止待ち修正はmini_r2/mini_r3共通。FAN_OFFゲイン・F405実装は不変。
- 実制御tickのASan/UBSan: 両fan状態・両旋回方向・前後発進について、残留角速度Iの解除、
  初回FF微分0、ずれを戻す左右出力、角度/目標/並進I保持、非吸引/走行中/旋回中の非解除を検証。
- production sessionのASan/UBSan: 全fanレート/300 ms待機/既存全段階abort・cleanupを維持。
  目標手前0.0005 mで停止プロファイルが完了すれば余分な到達待ちなし、
  位置0.001 m不足・速度0.030 m/sは整定timeout、通常迷路条件は従来どおり到達待ちと確認。
- 停止/ゲイン切替/速度feedback・機体runtime profile、path219件、mode6全10項目・
  最短接続2736経路、route precompute14210件、F413/F405 Debug build、diff check PASS。
  F413 RAM274160 B、Flash372148 B。経路事前計算の数値は不変、入力SHAのみ更新。
  コミット用SHAには無関係なローカルmode2加速度編集を含めない。
- ハードウェアコマンド列なし。UART・flash/reset・モータ/ファン・走行・NVM操作なし。
  NVM/log schema・`.ioc`・stable保存点の変更なし。
  ローカル解析・比較グラフはGit対象外 `build/suction_startup_review/`。

まず同じ90°で発進・停止を確認し、次に180°で速度低下と旋回追従を確認する。
この変更後の実測を確認するまでは、吸引制御調整の完了とはしない。
