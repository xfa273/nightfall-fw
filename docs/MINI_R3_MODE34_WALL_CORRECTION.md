## 前壁補正

F413の最短小回り入口は次式を使う。

```text
front_target = F_ALIGN_TARGET_MM + DIST_HALF_SEC - dist_offset_in
mode3       = 45 + 45 - 0.6 = 89.4 mm
mode4       = 45 + 45 - 0.8 = 89.2 mm
```

`val_offset_in` / `fwall_kx`はF405互換欄であり、F413のこの処理では
使わない。そこへADC閾値や新ゲインを書いても動作は変わらない。
`F_ALIGN_TARGET_MM`やLUTを変更すると探索・壁合わせにも影響するので、
走行中の累積位置ずれを校正誤差とみなして変更しない。

実際の`sensor_distance.c`とmini_r3の現LUTをホストでコンパイルし、
PCHIP・FR/FL/合計の測定範囲を確認して換算した。
小回りコア開始の前壁距離は以下。時系列の値であり、同一地点の反復ではない。

| mode/case | 小回り開始時の前壁距離（mm） |
| --- | --- |
| 3/1 | 94.04, 87.32, 90.75, 90.71 |
| 4/1 | 93.87, 89.41, 92.16, 96.84, 99.28, 91.80（最終旋回は不完全） |
| 4/2 | 94.47, 90.00, 91.25 |

前壁目標より遠い箇所が多く、mode4/case1では後の直線進入で差が増える。
まず既存目標で入口位置を揃える方針とし、独立した前壁バイアスは追加しない。
既存補正は入口距離の短縮または最大10 mmの延長で、到達位置を無制限に
補正するものではない。99.28 mmの例は差が約10.08 mmあり、全誤差を
必ず吸収できるとはしない。大回り入口にこの前壁処理は適用されない。

## 壁切れ閾値と追加距離

補正OFFでは壁切れイベントがラッチされないため、イベント0件を
「壁切れが無い」とは解釈しない。右側の直進中壁ありADCは概ね
500〜700、壁切れ後は20〜80。旧Low=1はこの床に届かず、長い微分窓の
検出を待つ。ログ上のwall-state変化は小回り開始の約19〜39 mm手前だが、
補正ONでは監視開始時に履歴がresetされるため、この距離をそのまま
`dist_wall_end`へ代入することもできない。

単純なADC交差だけを見たHigh=550 / Low=450・追加3 mm案は棄却した。
実処理では最後の45 mmを監視し、開始時ADC>Highで壁ありを初期化する。
この時点の値は既に約300〜550まで下がる場合があり、高いHighでは
初期化に失敗して検出を逃す。High=350 / Low=300なら、通常の壁を
保持しつつ微分判定より先に低下を捉えられる。

小回り前に十分な直線がある箇所では、旋回前25行までの有効前壁値から
`median(走行距離 + 前壁距離)`を壁の前後位置の基準にした。
検出位置の推定には最後の45 mmでresetした実`f413_wall_runtime.c`を使う。

```text
小回り: 検出後の直進 = 45 + dist_wall_end、その後にdist_offset_in
前壁目標までの整合から:
dist_wall_end = median(distance + front_LUT_mm) - detected_distance - 135
```

| mode/case・旋回開始seq | 新閾値での右検出距離（mm） | 前壁基準から推定した追加距離（mm） |
| --- | ---: | ---: |
| 3/1・2749 | 465 | +0.35 |
| 3/1・3384 | 検出なし | 監視開始時に既にLow未満、名目距離へfallback |
| 4/1・2865 | 468 | -1.00 |
| 4/1・3383 | 979 | -1.36 |
| 4/1・3998 | 1601 | +0.28 |
| 4/2・2734 | 473 | -5.53（減速中、定速とは分ける） |

定速4箇所の中央値は-0.36 mm、範囲-1.36〜+0.35 mmなので、
1 mm量子化の走行距離と数ms保持されるADCに対して非zeroの追加距離を
同定する根拠は弱い。`dist_wall_end=0`を暫定採用する。
case2は壁切れ付近で約1.4 m/sから小回り1.0 m/sへ減速している。
補正ONの長い直線は最後の45 mmに入る前にターン速度へ合わせるため、
このOFF軌道の-5.53 mmをモード全体へ適用しない。

再生にはADC4チャネルの値変化を`sample_sequence`の代わりに使い、
監視窓をコア開始距離から逆算した。rawのsequence・サブmm距離・正確な
foreground poll時刻は保存されていないため、実機と同一時刻の保証はない。
ログの飽和flagは参照できるが、前壁raw on値・sample ageも復元できない。
静的なLUT校正・光学遅延・スリップ・姿勢の誤差は分離できていない。

左は該当する直線進入の反復不足につき右と同値の仮置き。
mode4の大回り90/180では、名目入口前の監視窓に確実な右壁低下が
見えない。大回りを検出させる目的でHigh/Lowを壁ありADCまで上げない。
未検出時は既存の名目距離で進む。大回り連続部も補正ONの次ログで検証する。
