# mini_r3 mode3/4 壁補正の暫定値（2026-09-26訂正）

現行は `mini-r3-wall-derivative-t0.27`。
**t0.26のHigh=350 / Low=300は撤回**し、mini_r2と同じ100/1へ戻す。
Low=1は微分検出を主体にする補助設定であり、不具合ではなかった。
前回は生ADCの閾値交差を主にする調整へ変えてしまった。
また、CSVのADC値変化をセンサ更新sequenceとして再生した評価も撤回する。
ADC・微分値は4レコードに1回の間引き保存で、同値の間も実センサは更新する。

| 項目 | mode3 | mode4 | 意味 |
| --- | ---: | ---: | --- |
| 前壁距離目標（機体中心から壁、mm） | 89.4 | 89.2 | 既存の式・LUTを維持 |
| 壁切れHigh / Low（左右） | 100 / 1 | 100 / 1 | mini_r2同様、壁あり初期化とraw fallback |
| 微分閾値 / 確認回数 | -200未満 / 2回 | -200未満 / 2回 | 既存の窓微分検出を維持 |
| `dist_wall_end`（mm） | **-15.0** | **-15.0** | 微分検出の遅れを含む暫定オフセット |
| 小回り検出後の直進（入口距離を除く） | 30 mm | 30 mm | 45 + (-15)、後退ではない |
| 大回り検出後の追加直進 | 0 mm | 0 mm | 既存実装は非正値で追加しない |

調整済みターン・速度・加速度・タイヤ径を保持する。補正ONの実機試走は未実施。
このオフセットは主に右小回り前の直線から推定し、左・大回りは未同定。

## mini_r2 / classic_r1との照合

- mini_r2は `params/f413_preorder` と共通の `f413_wall_runtime.c` を使用。
  mode3/4は左右High100/Low1、`WALL_END_DERIV_FALL_THR=200`。
  `dist_wall_end`はmode3=1、mode4=0で、機体固有の距離なのでそのまま転用しない。
- classic_r1は `sensor.c:wall_end_update_deriv/detect_wall_end` を使用。
  `drive_reset_before_run()`がDERIVモードを選択する。mode3/4は左右High200/Low1、
  微分閾値200、`sensor_kx`で閾値を補正する。距離追加は両モード1mm。
- 両者とも隣り合う18サンプルずつの和の差を9で割る36サンプル窓を使う。
  Highで壁ありを初期化し、Low未満でも壁なしへ遷移するが、DERIV時は
  壁ありかつ微分<-200が2回続くことでも壁なしへ遷移する。
  アーム中の有り→無しだけをラッチする。
- **式の一致と更新周期の一致は別**。classicはADC完了時（設計約6kHz）に
  微分を更新し、1kHzで判定する。F413/mini_r2・r3はforeground poll時に
  新しいsnapshot sequenceを確認して更新・判定する。今回のログは約2msの
  pollモデルと整合する。共通実装の更新経路・周期は変更していない。

High/Lowを上げて微分より先に切る方法ではなく、従来の微分閾値200を
維持したまま、検出後の移動距離をmini_r3のログに合わせる。

## 前壁補正

F413の小回り入口は `F_ALIGN_TARGET_MM + DIST_HALF_SEC - dist_offset_in`。
mode3は45+45-0.6=89.4mm、mode4は45+45-0.8=89.2mmを維持する。
`val_offset_in`と`fwall_kx`はF405互換欄で、このF413処理には使われない。
静的LUTや探索と共用の45mm目標を、走行の累積ずれに合わせて変更しない。

実`sensor_distance.c`と現mini_r3 LUTのPCHIPで、記録された小回り開始付近の
FR+FLは約87〜99mmに相当する。ただし行に展開された保持値は最大3レコード前。
今回の距離推定は **seq%4==0の実保存行だけ** を使い、古いADCを新しい位置と
組み合わせない。前壁処理は入口短縮または最大10mm延長で、全誤差を必ず
吸収するものではない。大回り入口には適用されない。

## 微分を基準にした追加距離の推定

ソースの `F413_TRACE_COMPACT_SLOW_PERIOD_RECORDS=4` とpack/expandを確認。
ADCだけでなく `reserved_i32_0/1` の微分値も4レコードごとに保持される。
旧解析の「ADC4チャネルの値が変わった時だけ微分窓を更新する」再生は、
実制御より長い窓を作るため採用しない。旧raw交差の距離表も撤回する。

新しい診断再生では、実保存行間のADCを線形補間し、実F413窓微分処理へ
1/2/3/4ms周期・各位相で入力する。長い直線の記録微分値との比較では
6区間とも最良は2msで、RMSは2.66〜8.44（ピークは約1000）。
これは欠落サンプルの復元ではなく、記録された微分値に整合する近似モデル。
補間・未知のpoll位相・ADC/位置の量子化の誤差が残る。

次に、小回りコア位置から入口距離と45mmを引いた監視開始位置で、
実処理と同じく壁状態・窓履歴をresetして100/1・微分200・2回確認を再生する。
前壁の基準はコア前28msの有効な実保存行から求める。

```text
front_anchor = median(distance + front_LUT_mm)
dist_wall_end = front_anchor - derivative_detected_distance - 135
```

135mmは「小回り前の半区画45mm＋区画入口から前壁90mm」。
前壁目標の式との整合で入口距離が相殺される。

| mode/case・小回り開始seq | reset再生の検出位置 mm | 追加距離推定 mm | reset位相±2msでの範囲 mm |
| --- | ---: | ---: | ---: |
| 3/1・2749 | 476 | -11.65 | -13.65〜-10.65 |
| 3/1・3384 | 988 | -17.80 | -20.80〜-13.80 |
| 4/1・2865 | 480 | -14.42 | -18.42〜-12.42 |
| 4/1・3383 | 991 | -14.56 | -16.56〜-12.56 |
| 4/1・3998 | 1612 | -12.15 | -14.15〜-10.15 |
| 4/2・2734 | 485 | -18.83 | -23.83〜-15.83 |

定速進入の中央値はmode3=-14.72mm、mode4=-14.42mmなので、両方を
**-15mm**に丸めた暫定値とする。精度1mmを主張するものではない。
mode4/case2の例は壁切れ付近で1.4→1.0m/sへ減速するOFF走行なので分ける。
補正ONの長い直線は最後の45mmへ入る前にターン速度へ合わせる。

既存の `run_straight_steps` は小回りに `45 + dist_wall_end` を加えるため、
今回の設定では正の30mmを前進する。大回りでは `dist_wall_end > 0` のときだけ
追加し、今回は追加なし。大回り連続部の後追いも同じ正値条件なので、
負値を後退指令として渡さない。**大回りを15mm早める設定ではない**。
未検出時の名目距離fallback、前壁補正、guard、case別有効化は既存どおり。

左の十分な進入データや大回りの確実な検出イベントはなく、その調整完了は
主張しない。無補正ログの推定だけでは姿勢・スリップ・光学遅延を分離できず、
補正ONログで検出位置と旋回入口を確認してから再調整する。
