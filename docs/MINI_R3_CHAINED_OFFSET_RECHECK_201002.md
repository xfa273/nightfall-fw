## 壁切れが発動しなかった理由

| 指標 | 今回1回目 | 今回2回目 |
| --- | ---: | ---: |
| R180最終保存点→L180開始点の時間 | 12ms | 11ms |
| 同区間のエンコーダ距離差 | 17mm | 16mm |
| 最後に更新され、以後保持された左微分 | -190 | -135 |
| 連続対間の壁切れラッチ | 0 | 0 |

前回の同距離差18/19mmから1/3mm短縮している。ただしコア最終保存点と開始点の差であり、
公称オフセット14mmそのものを高精度に測定した値ではない。累積距離の絶対値も前区間の
誤差を含むため、2回目の旋回開始位置が迷路内で何mm変わったかとは同一視しない。

今回1回目の左ADCはseq2528/2532/2536で567→333→50、左微分は0→-41→-132。
seq2540にはgate OFF、最後の左微分は-190で保持される。
2回目はseq2524/2528/2532で422→244→41、seq2528/2532の微分は-9→-62、
seq2536にはgate OFF、最後は-135で保持される。gate ON中も、終端値も、
条件「微分<-200を異なる2更新で確認」を満たさない。
slow項目は4レコードごとの実保存であり、間の保持行を新しいセンサ更新として数えない。

原因として重要なのは、**前後オフセット境界では初期化しなくなったが、旋回終了後の
統合区間入口では依然として微分履歴を初期化している**こと。
`f413_path_run_drive_chained_offsets()`が`f413_wall_runtime_end_clear()`を呼び、
最初のpollで36要素をその時点のADC値で埋める。旋回中のpath処理はこの微分を更新しない。
立ち下がりの途中の値を初期値として約14mm/1400mm/s=10msしか蓄積できず、
今回の波形では閾値と2更新確認に間に合っていない。High/Lowは100/1の補助判定であり、
ADC40〜50ではLowを下回らない。検出がないので`dist_wall_end=-23`も作用しない。

## 次の修正候補と再生確認

全ターンの統合区間は維持し、次は微分履歴の準備時期を修正する。

1. 次が連続ターンの場合、前ターンの旋回終盤だけで微分履歴を準備する。
2. 補正は統合オフセット区間だけ許可し、入口では履歴を残して検出状態を切り替える。
   古い検出ラッチや旋回中の判定をそのまま次のターンへ持ち込まない。
3. 同じ本番判定を保存波形で再生し、短い区間でも新しい更新で検出することと、
   旋回由来の別の立ち下がりを拾わないことを検証する。

今回の本番`f413_wall_runtime.c`をhost共有libraryとしてコンパイルし、実保存された
4ms ADCを線形補間して2ms周期で入力した。これは補間を含む仮想再生で、実測検出時刻ではない。
旋回終了周辺の初期化位相を0/1/2msずらした3条件では、現方式は両走行とも未検出。
位相1msの最終微分-196/-136は実保存-190/-135に近い。
同じ式・閾値で20ms前からgate OFFで履歴を準備すると、今回1回目は従来のL180開始より
3〜4ms前、2回目は4〜5ms前で検出した（おおむね4〜7mm相当）。
40ms以上を無制限に引き継ぐと区間入口付近ですぐ検出する例があり、旋回中の光学変化を
混ぜる問題がある。したがって「常時監視して履歴を全て残す」だけの修正は避ける。
20msは実装済み/確定値ではなく候補。短いターン、左右/斜め、誤検出、実sample位相を含めた
検証が必要で、今回の再生だけで接触回避を保証しない。

## 追加解析：壁の消失と接触兆候の時間差、早期判定の余地

ユーザの追加質問に対し、2回目L180のコア開始を0msとして比較した。
ここで接触時刻そのものは計測しておらず、実角速度の最初の急落を接触兆候の基準とする。

| 実保存された現象 | 今回1回目 | 今回2回目 |
| --- | ---: | ---: |
| -15msの左ADC | 691 | 611 |
| -11msの左ADC | 567 | 422 |
| -7msの左ADC | 333 | 244 |
| -3msの左ADC | 50 | 41 |
| 角速度の急落開始 | +92ms | +89ms |
| ADCが壁なし付近になってから急落まで | 95ms | 92ms |

したがって、壁が見えなくなる変化は、ログに表れる強い接触兆候より約0.1秒早い。
センサの変化が衝突後に出ている状況ではない。上記急落時は予定ω約1929°/sに対して
実ωが前サンプル1933.5→1642.9、1918.0→1672.5°/sへ落ち、次サンプルでは845.5/509.1へ
さらに低下する。前節の再現可能な「差>400」基準はその次の+93/+90msを指していた。
低ADC保存点から急落までのエンコーダ距離差は133/130mmだが、旋回中の走行距離であり、
壁までの直線距離や補正できる余裕距離ではない。

旋回開始位置を修正するのに使えるのは、合計14mmの統合オフセットを走る約10ms。
それ以後の約90msはすでに2本目の旋回中で、開始位置を巻き戻すことはできない。

### 閾値・判定方法の比較

現在の本番Cをhost用に複製し、比較閾値/確認回数の2定数だけを可変化した。
元定数で本番版と320回の更新（gate OFF/ON、同sample再読出しを含む）の検出/微分値が一致。
20:10の2波形を4ms実保存点から補間し2ms更新、初期化位相0/1/2msで再生。
前倒しは**現在の2本目旋回開始時点よりどれだけ前に判定できるか**であり、
未発動の現行壁切れイベントとの差ではない。距離は同じログのオフセット直進中の距離差。

| 変更候補（原則2更新確認） | 検出時刻の前倒し | 直進距離相当 | 今回2波形×3位相での結果 |
| --- | ---: | ---: | --- |
| 現行：閾値200、入口reset | なし | — | 6条件とも未検出 |
| 閾値150だけ | ほぼなし | — | 5条件未検出、1条件は旋回開始と同時 |
| 閾値100だけ | 0〜2ms | 0〜3mm | 2回目の2位相は未検出 |
| 閾値50だけ | 1〜4ms | 2〜5mm | 6条件で検出。ただし早める量は小さい |
| 確認回数だけ2→1、閾値200 | ほぼなし | — | 5条件未検出、1条件は開始と同時 |
| 終盤20msの履歴準備、閾値200 | 3〜5ms | 4〜7mm | 6条件で検出 |
| 終盤20msの履歴準備＋閾値150 | 5〜8ms | 7〜11mm | 6条件で検出 |
| 直近4msのADC低下>150＋2更新確認 | 7〜9ms | 10〜13mm | 6条件で検出 |

最後の候補は18+18窓の値の閾値を150にする意味ではない。
`ADC(t-4ms) - ADC(t) > 150`という別の短時間差分で、過去値>=300を壁の存在確認とし、
gate ON後の異なる2更新で成立させる例。旋回終盤から最低4ms分の履歴を保持する。
補正許可は統合オフセット内だけで、High/Lowの生値遷移を主判定にする案ではない。
低下量100なら7〜10ms前だが、200では今回2回目を検出できず、感度との交換条件がある。
前回19:14の2波形でも低下量150の候補は6〜10ms前で検出した。
ただし4走行とも同じ左壁端の例で、雑音や他の旋回・壁配置に対する誤検出率は評価できない。

この比較からは、全体の閾値を200→50にするより、連続ターンの区間に限定した
短時間差分と履歴準備を検証する方が、約10mmの入口前倒しを狙いやすい。
生の2msセンサ列は保存されておらず、各時刻は数ms幅の推定。2回確認の待ち時間は含むが、
検出後のforeground処理と旋回指令切替遅延は含まない。したがって実旋回の前倒しは小さくなり得る。
何mm前倒しすれば後部接触を避けられるかは、この再生だけでは決められない。
候補値をFWへは適用していない。
