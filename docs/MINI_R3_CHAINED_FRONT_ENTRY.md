# mini_r3 連続ターンの前壁補正

2026-09-27、`mini-r3-chained-front-t0.29`。
ユーザ指示により、次ターンの前壁目標を前ターンの後オフセット中から監視する。
[直近4本の確認](MINI_R3_FOUR_LOG_RECHECK_20260927.md)で確認した、
入口補正を開始する前に目標を通過してしまう問題への対応。

## 動作

- 経路コードで直接隣接するターンだけを対象とする。直進・斜め直進を挟む場合は対象外。
- 次ターンが既存の前壁補正対象（現在は小回り90°、正の前オフセット）で、
  前壁補正ON・test mode OFFの場合、前ターンの旋回終了直後から後オフセットの間に監視する。
- 目標は従来と同じ `F_ALIGN_TARGET_MM + DIST_HALF_SEC - 次ターンのdist_in_mm`。
  距離も従来の有効判定付き `front_unwarped_mm` を使用する。
- 有効な前壁距離が目標以下になったら、後オフセットの残りを打ち切り、
  次ターンの前オフセットを省略して旋回へ移る。既に目標以下の場合、後オフセットが0の場合も
  その場で判定する。判定は既存の1 ms guarded wait単位であり、物理的な遅延ゼロを保証しない。
- 到達を1ターンだけ引き継ぐので、直後にセンサが無効になっても前オフセットを再実行しない。
  距離管理の基準を実測位置へ戻し、省略距離を後続の直進で取り戻さない。
- 未到達／センサ無効なら公称の後オフセットまで進み、次ターンの従来の入口処理へ移る。
  後オフセット自体は延長しない。入口側の最大10 mm延長、停止guard、timeoutは維持する。

`F413_MOTION_CHAINED_FRONT_ENTRY`（bit 8）を独立追加し、mini_r3だけが明示的に選択する。
boot policyはr3=`0x000001FF`、r2=`0x00000000`。
r2復旧・再導入保留の方針に従い、r2は従来動作。F405は変更しない。
前壁基準、dist_wall_end、ターン寸法、速度・加速度・ゲインの数値は変更しない。

## 検証と次の実走

`sh tools/hil/run_f413_chained_front_tests.sh` は本番path executorをホストで実行し、
r3/r2両profileで以下をASan/UBSan付き確認する。

- 目標到達前後・出口境界・既通過・出口0、異なる次ターン入口値、遅れて有効になるセンサ。
- センサ無効、前壁補正OFF、test mode、非対象ターン、大回り連続の壁切れ経路。
- 入口省略時のprofile非発行・距離基準、1回だけの到達引継ぎ、入口の延長上限。
- mode3/4の左右全8通りの3連続ターン、直進を挟む経路、終了cleanup。
- 後オフセット中の各guard中断、停止した距離のtimeout、tickのwrap。

機体選択・161 scalar監査、吸引session/PWM、path linear 219件、
既存の制御・探索・経路計画・mode dispatch差分試験、F413/F405 Debug buildもPASS。
既存差分試験は旋回間の実行タイミングを比較しないため、今回の専用試験をCIへ追加した。
route tableは入力fingerprintのみ更新し、数値内容は維持する。

実機操作は一切行っていない。Flash/UART/reset/モータ/fan/走行/NVM書込みなし。
ホストの理想距離入力は滑り・姿勢・センサ遅延を再現しない。
次のmode3/4 case3ログでは、連続小回りの各コア開始時の前壁距離、
前コア終了から次コア開始までの移動量を比較する。
現在のローカル調整値では目標mode3=89.4 mm／mode4=89.2 mm。
コア終了時点で既に目標を越えた場合は即時に次旋回へ進むが、過走行を後退で取り消す処理ではない。
