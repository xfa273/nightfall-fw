# mini_r3 ターン前壁補正の換算基準（2026-09-21）

## 結論

追加測定を受領し、t0.9で前壁LUTを**40..110mmの15点**へ拡張した。
80mmは再測定FR599/FL568で置換、85..110mmを追加、40..75mmは維持。
90mm入口と以下の全目標が測定範囲内になった。補正式・ゲイン・入口距離は
変更しない。今回はソース更新とホスト検証までで、実機書き込み・走行は未実施。

F413の探索小回りと最短小回りは、既に前壁FR+FLの**距離換算値**で
旋回開始位置を補正する。`val_offset_in`（630/650等）や`fwall_kx`は
F405互換のパラメータで、現F413のこの補正処理では使用しない。
これらのADC値を換算してもF413の旋回開始は変わらない。

実処理は `f413_search_step.c` と `f413_path_run.c` の
`drive_front_wall_entry_segment`。両方とも以下の式で目標を作る。

```text
前壁距離目標 = F_ALIGN_TARGET_MM + DIST_HALF_SEC - dist_offset_in
mini_r2     = 7  + 45 - dist_offset_in   （旧テーブルの距離基準）
mini_r3     = 45 + 45 - dist_offset_in   （機体中心から壁まで）
```

従って既存の同じ中心合わせ目標に対応させる換算は **r3 = r2 + 38 mm**。
これは既存の制御目標7/45mmに基づく対応であり、mini_r2の旧治具原点を
今回独立に実測・同定したものではない。mini_r2のLUT自体は変更しない。
mini_r3の `F_ALIGN_TARGET_MM=45` への移行時点でこの換算は適用済み。
今回、幾何パラメータや未使用ADC閾値に追加の変更は行わない。

## 追加測定で解消した範囲不足（履歴）

追加測定前のmini_r3前壁LUTは中心基準40..80mmの実測9点だった。
80mmのFR/FL/合計は **565 / 595 / 1160**、45mmは
**2508 / 2494 / 5002**だった。遠距離の実測不足は今回の追加データで解消した。

`f413_wall_distance_convert_snapshot` はテーブル外の値を無効とし、
`front_unwarped_mm` はその値を制御へ渡さない。ターン入口処理も、開始時に
有効な前壁距離が取れなければ、センサ補正なしのエンコーダ距離走行へ戻る。
区画入口の名目距離は中心から90mmなので、**目標が80mmの設定でも、
入口90mmを測れなければ補正が開始されない**。
この条件はコードからの確認で、ユーザの今回の各走行ログは未取得。

このため、ADC閾値だけの換算では問題を解決できない。
中心基準80..110mmの新しい実測を受領し、PCHIP・有効範囲を更新した。
測定元と再生成手順は `params/mini_r3_0/calibration/README.md` を参照。
遮光前データの混在、外挿値の実測扱い、有効範囲ガードの解除はしない。

前壁補正のみの独立オフセットは現状ない。`dist_offset_in`を変えると
前壁なし時の入口幾何も変わるため、未使用の`val_offset_in`と混同せず、
次は追加LUTを書き込んで前壁あり/なしの差を確認し、必要な調整を決める。
