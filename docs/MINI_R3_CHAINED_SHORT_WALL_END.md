# mini_r3 連続ターンの短時間差分による壁切れ判定

2026-09-27、`mini-r3-chained-short-wall-t0.33`。
ユーザ承認により、[20:10ログの比較](MINI_R3_CHAINED_OFFSET_RECHECK_201002.md)で
最も早い検出が期待できた短時間差分方式を実装した。
前後オフセット統合だけでは検出できなかった連続180°間で、立ち下がりの初期を捉える。

## 判定と適用範囲

左右それぞれ、`4ms前のADC >= 300` かつ `4ms前のADC − 現在ADC > 150` を
**補正区間に入ってから異なる2回のセンサ更新で連続確認**すると壁切れとする。
従来の長窓微分判定も並行して動かし、先に確定したイベントを採用する。
High/Lowの補助判定や従来の微分閾値は変更していない。

- mini_r3の通常迷路走行で壁切れ補正ON、かつ直後の経路コードもターンの場合に限定する。
  左右小90、大90/180、45入/出、V90、135入/出の全16種類を共通に扱う。
- 前ターンの旋回末尾8msは履歴収集だけを行う。旋回中には補正せず、確認回数も持ち越さない。
  旋回終了後の「後オフセット＋次の前オフセット」全体で新判定を許可する。
- 同じsample sequenceや同じ時刻の再読出しは数えない。欠落・飽和・更新間隔3ms超では
  短窓の履歴と確認回数を破棄する。直後に古い履歴で確定させない。
- snapshotに取得時刻がないため、前景処理が新sampleを観測したHAL時刻を使う。
  4ms前の値は隣接観測間の線形補間で求める。許容する間隔は3ms以下、外挿はしない。
  1/3msの周期揺らぎ・HAL tick wrapにも対応する。
- 補正OFF、test mode、単独ターン、間に明示直進がある場合は新処理を実行しない。
  新policy bit12 `F413_MOTION_CHAINED_SHORT_WALL_END` はbit11の区間統合を必須とする。
  mini_r3は0x1FFF、mini_r2は従来の0。F405の動作ソースは変更しない。

定数は `f413_wall_runtime.h` の `F413_WALL_RUNTIME_CHAINED_*` にまとめた。
8要素の短窓履歴は従来の長窓履歴と分離し、区間終了・中断時に破棄する。

## 検出後の動作とログ

検出後の距離計算・前壁目標の優先・次入口の一度だけの消費はt0.32を継承する。
mode4の大180→大180は残距離 `max(0, -23 + 1) = 0mm` なので、検出後すぐに
次の旋回へ移る。`dist_wall_end`、前壁目標、ターン設定、PI/FFの値は今回変更しない。
後オフセットの終わりまで待ってから検出結果を適用する動作にはしない。

既存 `reserved_u16_0` の壁観測フラグに以下を追加した。

| bit | 意味 |
| --- | --- |
| 0x0800 | 短時間差分の補正区間が有効 |
| 0x1000 | 右の検出を短時間差分で確定 |
| 0x2000 | 左の検出を短時間差分で確定 |

左右の既存検出ラッチ0x0040/0x0080も立つ。方式のフラグは既存ラッチと同じ期間保持し、
次のコア中にも確認できる。既存の微分・検出時微分列の単位は長窓のまま維持するため、
新方式なら検出時の長窓微分が-200未満でなくても正常。
dump-timeテキストメタに有効状態・条件・フラグ定義を追加した。
binary/NVM形式、レコードサイズ、準備10ms/走行1ms、slow項目4ms保存は不変。
メタはdump時点の設定であり、過去走行時のFW識別を保証するものではない。

## ホスト検証

本番wall runtimeとpath executorを使ったASan/UBSan試験で確認した。

- 4ms差分、厳密な150超/過去300以上の境界、左右、補正開始後の2更新確認。
  重複sample、事前に完了した壁切れ、単発ノイズ、一定値、上昇、緩やかな低下では誤確定しない。
  欠落・飽和・更新停止・長い間隔・周期揺らぎ・tick wrapを確認。
- 本番pathで旋回末尾だけの収集、14mm区間内の短縮、次入口の省略、中断後の状態解除、
  補正OFF/test/単独ターン/r2の迂回、方式フラグと既存微分列の保持を確認。
- 19:14の2波形と20:10の2波形について、4ms保存ADCを補間した2ms更新と3通りの
  観測位相で本番判定を再生（計12ケース）。直近2波形は従来の次旋回開始より7〜9ms、
  前回2波形は6〜10ms前に検出。直近1400mm/sでは約10〜13mmの前進に相当する。
- 既存の全16×16種類×mode2〜7の統合区間試験、前壁優先・境界・正負残距離・各中断、
  前壁補正、吸引session、180°追従、機体policy、r2/r3歴史版の互換試験がPASS。
  互換比較は制御/探索/計画/dispatchであり、新補正の実走同一性を意味しない。
- trace compact往復、route table 14210比較、F413/F405 build、diff checkがPASS。
  F413 RAM274376B、Flash387372B。生成route tableは入力指紋のみ更新し、数値は不変。

主要再現コマンド: `sh tools/hil/run_f413_chained_offset_tests.sh`。
一時結果は `build/chained_short_20260927/` に保存する。
既存のローカル機体調整・flashing関連編集は保持し、このコミットには含めない。

実機コマンド列はなし。ST-LINK/UART/書込み/reset/motor/fan/run/NVM操作は実施していない。

## 次の実走で確認すること

再生結果は4ms保存波形の補間であり、新しい実測ではない。機体の動きが変わった後の
センサ波形・指令引継ぎの遅れ・後部接触の解消までは確認できない。
対象4波形は同じ連続左180入口であり、他のターンや壁形状の誤検出率も未確認。

次のmode4/case3では連続対間の左方式フラグ0x2000、既存左ラッチ0x0080、
2本目の旋回開始時刻/位置、旋回中の角速度急落・PWM飽和、目視の後部接触を照合する。
他の連続ターンが早過ぎないかも確認してから、必要なら閾値・距離を再調整する。
