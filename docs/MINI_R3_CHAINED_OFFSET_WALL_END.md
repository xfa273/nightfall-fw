# mini_r3 連続ターンのオフセットを共通の壁切れ監視区間へ統合

2026-09-27、`mini-r3-chained-offset-wall-t0.32`。
ユーザの目視では、連続180°の2本目の旋回開始が遅れ、機体後部が壁へ接触している。
19:14ログにも連続対間で左壁の立ち下がりがあるが、短い後オフセットだけの監視では未検出だった。
依頼に基づき、ターン種類によらず**前ターン後オフセット＋次ターン前オフセット**を
一つの直進区間として実行し、区間全体で壁切れ判定する。

## 動作

- pathの直後のコードもターンなら統合対象。小90、大90/180、45入/出、V90、135入/出と左右の
  全16種類を同じ処理へ渡す。明示的な直進・斜め直進コードを跨がない。
- 監視の開始時に一度だけ微分履歴を初期化し、後オフセットと前オフセットの境界では
  gateを切らず、履歴も初期化しない。両オフセット長が0でも境界判定を行う。
- 一つの速度profileで、前ターンの速度から次ターンの速度へ合算距離で接続する。
  両者が同速なら定速、異なる場合は従来の前オフセットだけより長い距離で速度を接続する。
- 区間実行済みの情報を直後の1ターンだけへ渡し、次の前オフセットを再実行しない。
  壁切れがなくても合計距離を一度走って次の旋回へ移る。距離基準は実測へ戻す。
- 壁切れ検出時は、未実行オフセットを検出点基準の距離に置き換える。
  残距離は `max(0, 基準距離 + dist_wall_end + 次の前オフセット)`。
  基準距離は既存の小回りの壁切れ基準を継承して45mm、その他のターンは0。
  次の前オフセットは式へ1回含まれるだけで、後で追加しない。
  mode4大180は `max(0, -23 + 1) = 0mm` なので、検出した時点で次の旋回へ移る。
- 次が小回りで前壁補正ONなら、同じ区間全体で次の前壁目標も監視する。
  前壁目標到達は壁切れ判定・後追いより優先し、残距離を打ち切る。
  前壁が有効でまだ遠い場合の既存上限付き追加接近（10mm）も維持する。
  側壁が見つかるまで無制限に直進する動作は追加しない。
- 側壁による方位制御のON/OFFは、旧出口・入口の設定を各区間で引き継ぐ。
  新しい検出専用APIにより、斜め系など方位制御OFFのオフセットでも壁切れを検出できる。
  その場合もログのgate表示はONとなり、直角走行用の壁制御は有効にしない。
- mode4大180の予定軌道FFは元の後オフセット終了時に解除し、次の入口へ持ち越さない。
  各中断経路でもgateと制御コンテキストを解除し、次のターンを開始しない。

## 適用範囲と保持した値

独立policy bit11 `F413_MOTION_CHAINED_OFFSET_WALL_END` をmini_r3だけに追加（0xFFF）。
壁切れ補正ONかつ通常迷路走行で有効。壁切れOFF/test modeは従来経路を使い、
前壁だけONの場合も既存の連続小回り前壁補正を維持する。
mini_r2はpolicy0のまま、F405ソース変更なし。

High/Low、微分閾値200/2更新確認、dist_wall_end、ターン角・速度・前後オフセット、
PI/FF係数は変更していない。既存ユーザ調整を保持する。
ログの10ms準備/1ms走行と複数走行保持、binary/NVM形式は維持する。
新動作の有効状態をdump-timeテキストメタへ追加した。
生成route tableは入力指紋のみ更新し、数値は不変。

## 検証

実機を動かさず、ASan/UBSan付きホスト試験で確認。

- 本番path executor: mini_r3 mode2〜7、全16×16種類の組合せに対して未検出/次入口内検出を検証
  （3072ケース、型の組合せ試験であり全組が有効な迷路経路という意味ではない）。
  次の入口が二重実行されないこと、境界での検出、出口/入口0、正負補正、前壁優先、
  補正OFF/test mode、全guard中断とtick wrap/timeoutを確認。
- 本番wall runtimeと本番統合処理を接続。2msごとの光学sampleで左右600→40、High100/Low1。
  13mm出口内で始まった低下が次の20mm入口側で微分-311/2更新確認となり、20mm地点で検出。
  旧出口13mmだけでは未検出。同じsampleの重複読出しを2回確認と数えないこと、sensor欠落、
  斜めオフセットで壁制御OFFのままgateを記録すること、次の接続へラッチを再利用しないことも確認。
- 既存の連続前壁、吸引/光同期/中断、mode4大180の予定軌道FF/独立policy/出口/中断、
  機体識別/新bit単独受理を検証。旧版とのr2/r3の制御8400件ずつ・探索120/122件・
  経路計画1296件ずつ・dispatch126件ずつも一致（新補正の走行一致を意味しない）。
- F413/F405 buildとdiff check PASS。F413 RAM274296B、Flash385660B。

ST-LINK/UART/flash/reset/motor/fan/run/NVM書込みの実機操作は行っていない。

## 次のログで確認すること

mode4連続180°の公称区間は13+1=14mm。境界をなくしても監視距離自体は14mmであり、
壁の変化が遅ければ、その区間内で微分の確定まで到達しない可能性は残る。
ホスト試験でも、14mm終了前に確定しない遅い入力は未検出のまま14mmで終了することを確認した。
直近の4ms保存センサ列だけから、変更後の検出発動やクラッシュ回避は保証しない。
次回は連続対間のgate/微分/検出ラッチと、2本目の旋回開始距離・後部接触の有無を確認する。
今回の変更だけで未検出が残る場合は、微分の遅れと監視開始位置の対応を実測して次の調整を行う。
