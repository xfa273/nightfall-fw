# mini_r3 unit002・2S非吸引の調整値保存点

2026-09-21、ユーザが非吸引のゲイン調整を完了と判断。
迷路でも基本的にmini_r2と同じ走行パラメータでよいと報告した。
作業ツリーの速度P0.24・角速度P0.45を、他の現行値とともに
`929f000` / `mini-r3-2s-fanoff-t0.8`へ保存した。
今回Codexが新たに走行ログや実機binaryを取得したものではない。
全mode・速度域・吸引・3Sを検証済みとする記録ではない。

## 非吸引ゲイン

`params/mini_r3_0/params.h` の `_FAN_OFF` を参照。

| ループ | P | I | D |
| --- | ---: | ---: | ---: |
| 並進速度 | 0.24 | 0.001 | 0 |
| 距離 | 2.0 | 0 | 0 |
| 角速度 | 0.45 | 0.006 | 0 |
| 角度 | 10.0 | 0.1 | 0 |

- 並進FF: static35、velocity0.035、acceleration0.004。
- 距離/角度のFFは各1。角速度/角加速度のPWM FFは各0。
- IMU加速度併用の速度推定は有効、窓30ms・gain1。
- 角速度プロファイル中だけエンコーダLPF（時定数3ms）を使用する例外は維持。
- 探索・最短の走行パラメータ配列はmini_r2と数値同一のまま。
- 左配線極性、IMUの向き/後方2.5mm補正、校正LUT・オフセットは変更しない。

## 前壁補正は別管理

換算基準は `docs/MINI_R3_FRONT_TURN_REFERENCE.md`。
F413はADC閾値ではなく既に距離判定を使い、中心基準への換算も適用済み。
標準探索の目標は82mm、低速探索80mm、通常の区画入口は90mm。
現LUTは40..80mmなので前壁補正用の測定範囲が不足している。
ユーザはこの後追加測定を行う予定。今回はLUT、入口距離、未使用ADC閾値を
変更せず、追加データ受領後にテーブルを更新する。

## 復元

manifestの`fw_commit`を別チェックアウトで参照すれば、この時点の
機種profile・走行配列・LUTをまとめて再現できる。ファイル単体の同一性は
manifestのSHA256でも確認できる。共有profileなので変更は両r3個体に及ぶが、
unit001のU2故障による駆動禁止は解除しない。

この保存点には新しいFRAMバックアップを含めていない。通常の復元で
identityやFRAMを消去・再登録しない。`runtime_settings.yaml`は運用メモであり、
現ツールによる自動適用には未対応。
