# 本体基板のマウント穴 Ø1.6 mm 化

2026-09-21、`HM_Nightfall-mini-2e_v1.kicad_pcb` のマウント取付穴4か所を
Ø1.1 mmからØ1.6 mmへ変更しました。編集正は
`cad/kicad/HM_Nightfall-mini-2e/` のKiCad PCBです。

## 穴の位置と加工表現

上面を通常の向きで見た位置です。中心座標の単位はmmです。

| 位置 | 中心X | 中心Y | 変更後の直径 |
| --- | ---: | ---: | ---: |
| 左上 | 136.501098 | 105.003598 | 1.60 |
| 右上 | 160.501098 | 105.003598 | 1.60 |
| 左下 | 136.503667 | 116.003598 | 1.60 |
| 右下 | 160.501098 | 116.003598 | 1.60 |

中心位置と基板外周を維持し、既存の `Edge.Cuts` 円の半径を0.55 mmから
0.80 mmへ変更しています。加工データでは非めっき内形として外形Gerberに
含まれます。スイッチ `POWER0` のØ0.9 mm固定穴は変更対象外です。

上側2穴と基板外周の設計上の残り幅は各0.20 mmです。
穴径拡大後の取付強度と実物の組付けは未確認です。

## 干渉を避けるための配線調整

- 左下: 表面の `+5V` 横配線を約0.258 mm下へ移動。
- 右上下: 裏面の `SWO` を0.20 mm内側へ移動し、隣接する `SWCLK` も
  0.10 mm内側へ移動。入口と出口は45度配線を維持。
- 右上: 表面の `BUZZER_PWM` を穴の左上へ迂回。その通路を確保するため、
  `BOOT0` ビア1個を0.40 mm左へ、隣接する表面配線を約0.117 mm左へ移動。

変更した配線の幅はすべて従来どおり0.254 mmです。
移動したビアは銅箔径0.7564 mm、ドリル径0.35 mmを維持しています。
部品、パッド、ネット、回路図、基板外周、設計ルールは変更していません。
銅箔ゾーンは再計算してPCBへ保存しました。

## 検証

KiCad 10.0.3で変更前後にゾーンを再計算してDRCを実施しました。

| 項目 | 変更前 | 変更後 |
| --- | ---: | ---: |
| エラー | 4 | 4 |
| 警告 | 112 | 112 |
| 未配線 | 0 | 0 |
| 新規DRC違反 | — | 0 |

違反種別・重大度・対象UUIDを比較し、すべて既存の違反であることを確認。
既存エラーは `C14` の外形クリアランス2件と、`U5` の35/47番パッドの
サーマル接続不足2件です。既存警告はレジストブリッジ99件、文字線幅11件、
配線の未終端1件、文字高さ1件です。

4穴とも銅箔と外形の0.20 mmクリアランスルールに新規違反はありません。
最も近い配線・ビアとの計算上の間隔は左上0.4045 mm、左下0.2689 mm、
右上・右下0.2235 mmです（Edge.Cutsの線幅0.001 mmを含む、ゾーンを除く値）。

保存後のオブジェクト比較で穴中心、部品・パッド、配線幅、ビア径・穴径、
ネットを確認しました。外形Gerberの4円がそれぞれ半径0.80 mmの半円2本で
出力されること、および3D描画で4穴が貫通していることも確認しました。

検証用出力はGit管理外の `build/main-mount-holes/` に保存しています。

は変更前の発注候補であり、このØ1.6 mm変更を含みません。
