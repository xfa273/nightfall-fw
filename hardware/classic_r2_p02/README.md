# classic_r2_p02（Nightfall 2）

classic r2 の試作案 p02 です。基板設計は KiCad 10 で [classic_r2_p02.kicad_pro](cad/kicad/classic_r2_p02/classic_r2_p02.kicad_pro) を開いて始めます。同名の回路図とPCBがこのプロジェクトの編集原本です。

初版は空の回路図と基板です。リポジトリ外のメカCADから受け取った外形・取付位置のDXFは [source/](cad/kicad/classic_r2_p02/source/) に置き、基板外形を `Edge.Cuts` に取り込みます。

部品表は [bom/](bom/)、メカとの位置合わせや設計変更の記録は [notes/](notes/) に置きます。
